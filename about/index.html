Verify any image

You don't have to trust this page. Every claim below is checkable from your terminal.

1 · Pull it

docker pull ghcr.io/tylerobara/containers/cnpg-postgres:18.6

2 · Verify the cosign signature

Keyless: the certificate identity is the workflow file that built the image, on main. A signature exists only when that build scanned with zero Low+ findings.

cosign verify \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  --certificate-identity-regexp '^https://github\.com/tylerobara/containers/\.github/workflows/postgres\.yml@refs/heads/main$' \
  ghcr.io/tylerobara/containers/cnpg-postgres:18.6

3 · Re-run the scan

grype ghcr.io/tylerobara/containers/cnpg-postgres:18.6@sha256:fcb13c5074c93a2059241be3f385a57fc17b2b6868aceec9e51a6142ede30f67
